# Машин birthday wishlist

Небольшой многостраничный сайт для дня рождения 26 сентября. Гости могут открыть каталог, отфильтровать подарки и забронировать один из них. Брони хранятся в локальной базе `wishlist.db`, поэтому подарок не смогут случайно выбрать два человека.

## Запуск

```powershell
cd C:\Users\masha\Desktop\1223\birthday-wishlist
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:BIRTHDAY_ADMIN_KEY = "придумай-свой-секретный-ключ"
python app.py
```

Открой `http://127.0.0.1:5050`. Владелице сайта доступна страница `/masha-admin`; ключ не хранится в коде — используй переменную окружения выше.

## Каталог

Виш-лист уже заполнен 17 товарами из Машиной общей корзины Золотого Яблока: с фото, прямыми ссылками и актуальными на 10 сентября 2026 года ценами. Цены в магазине могут меняться, поэтому в каталоге есть маленькое предупреждение перед карточками.

Карточки разделены на «Уход», «Макияж», «Волосы» и «Остальное». Исходные данные находятся в `INITIAL_WISHES` в `app.py`. После первого запуска список хранится в `wishlist.db`, а брони не сбрасываются.

Если в корзине появятся новые желания, пришли обновлённую ссылку — добавлю их в сайт без потери уже сделанных броней.
