# Публикация на Vercel

`app.py` уже является точкой входа Flask, а `requirements.txt` и `vercel.json` добавлены в корень проекта.

1. Установи Vercel CLI: `npm i -g vercel`.
2. В папке проекта выполни `vercel link` и выбери или создай проект.
3. В панели Vercel открой **Settings → Environment Variables** и добавь `BIRTHDAY_ADMIN_KEY` — придумай длинный отдельный пароль для страницы `/masha-admin`.
4. Выполни `vercel` для тестовой ссылки, затем `vercel --prod` для публикации.

Важно: локальная база SQLite подходит для запуска на компьютере, но не является постоянным хранилищем на Vercel. Чтобы брони и разблокировки работали после публикации, нужно сначала создать Vercel KV или Postgres и передать параметры подключения. Не добавляй Vercel-токены в `app.py`, `.env` в git или в сообщения.
